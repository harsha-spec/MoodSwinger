# MoodSwinger 🎵🌌

MoodSwinger is a Spotify-powered web application that visualizes a user's listening habits in an interactive "music universe".

## Features
- Spotify OAuth login
- View top tracks and artists
- Interactive universe visualization
- Time-range selector (4 weeks, 6 months, all time)
- Clean UI with animated stars and orbits

## Tech Stack
- Python
- Flask
- Spotify Web API
- HTML / CSS / JavaScript
